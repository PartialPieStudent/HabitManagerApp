# NetWatch — монитор сетевых подключений

Кроссплатформенная (Windows + Linux) программа на C# / .NET 10 / Avalonia, которая:

- показывает все TCP/UDP-соединения (IPv4 и IPv6): процесс, PID, локальный и удалённый адрес, имя хоста, состояние;
- определяет направление: **входящее**, **исходящее** или **слушающий порт**;
- фиксирует **время появления** и **длительность** каждого соединения;
- ведёт **историю** в SQLite;
- проверяет адреса через **Kaspersky OpenTIP** и анализирует соединения с помощью **ИИ** (Claude API или локальная модель через Ollama);
- позволяет добавлять свои анализаторы через интерфейс `IConnectionAnalyzer`.

## Быстрый старт

```bash
# 1. Нужен .NET 10 SDK: https://dotnet.microsoft.com/download
dotnet --version

# 2. Сборка
dotnet build

# 3. Консоль: разовый снимок
dotnet run --project src/NetWatch.Cli -- --once

# 4. Графическое приложение
dotnet run --project src/NetWatch.Desktop
```

Для полной информации о процессах запускайте **от администратора** (Windows) или через **sudo** (Linux).
Подробности, настройка ключей и пошаговый план развития — в [GUIDE.md](GUIDE.md).
